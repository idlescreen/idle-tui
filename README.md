# IdleScreen TUI (`idle-tui`)

Interactive terminal host and controller dashboard for **[IdleScreen](https://idlescreen.github.io)**.

Website: **[https://idlescreen.github.io](https://idlescreen.github.io)**

---

## ⚡ Quick Install

```bash
curl -fsSL https://idlescreen.github.io/packages/install.sh | sh
```

Or install via package manager:

```bash
sudo dnf install idlescreen
```

---

## 🚀 Usage

Launch the TUI interface in any terminal window:

```bash
idlescreen tui
```

> **Desktop Launcher:** Installing `idlescreen` also installs an official **IdleScreen** desktop application launcher entry into your Desktop Application Menu.

---

## 🎹 Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Tab` | Switch between Dashboard, Savers, and Settings panes |
| `Space` | Toggle screensaver engine On / Off |
| `Enter` | Trigger screensaver immediately |
| `c` | 1-Click Install COSMIC DE Panel Applet (COSMIC DE only) |
| `q` | Quit TUI |
